# MarketFit Job Lens

[English](README.md) · 简体中文

一个 Chrome 侧边栏扩展：读取你当前标签页里的职位描述，和你的 PDF 简历逐条对照，回答一个
问题——**这份工作值不值得你花一个晚上去投**。

界面和分析结果都支持中文与 English。

它不是面试结果预测，不是法律意见，不做移民资格判断，也不会替你自动投递。

---

## 安装

从 [Releases](https://github.com/dong845/marketfit-job-lens/releases) 下载最新的
`marketfit-job-lens-*.zip`，解压后：

`chrome://extensions` → 打开**开发者模式** → **加载已解压的扩展程序** → 选择解压出来的
文件夹。

点击扩展图标打开侧边栏。标题旁会显示当前加载的版本号——如果它和你刚装的版本对不上，说明
Chrome 还在跑旧代码，需要重新加载。

## 第一次设置

1. **上传 PDF 简历。** 必须是文字版 PDF，不能是扫描件——文字在你的浏览器里提取，图片里
   没有文字可提。
2. **说明你能不能在职位所在地工作。** 一个下拉框。留在**「未知」**不会产生任何影响；如实
   选择后，雇主写明的条件会与它对照。
3. **选一家 AI 服务并粘贴 API Key。** 见下方表格。Key 只存在于打开着的侧边栏里。

## 怎么用

打开一个职位页面，点击**「用 AI 分析当前职位」**，然后从上往下读：

| 你看到的 | 它在告诉你什么 |
| --- | --- |
| **结论那个词** | 可以直接投 / 值得投递 / 补齐后再投 / 建议先跳过 |
| **下面那条彩色条** | 必需要求的覆盖情况：满足 / 部分满足 / 缺失，按数量分段 |
| **成本标签** | 投递要付出什么——只改措辞、一个晚上、更久，还是投递前补不上 |
| **什么能改变这个结论** | 最能推动这次申请的那一处改动 |
| **雇主明确写出的条件** | 他们的原话，外加一句能问出结果的问题——那句话可以直接发出去 |
| **岗位要求** | 每条标注必需项/加分项与满足程度，硬性门槛排在最前 |
| **需要补齐的缺口** | 附带**怎么补**，以及哪些在投递前补不上 |
| **接下来做什么** | 完整计划，按时机分组并编号。这份分析要你做的事，都在这里，且只出现一次 |
| **你该问他们什么** / **你的简历没说清楚的地方** | 两件不同的事——后者只有你自己能补 |

**「打开完整报告」**会用整页宽度展示同一份分析，可打印或留存。报告在当前浏览器会话内有效。

如果页面读不出来（登录墙、重度单页应用），用**「编辑职位文本」**把 JD 粘进去。**你粘贴的
文本不会被重新抓取覆盖。**

## 工作原理

值得了解，因为这决定了输出是「可核对的」而不只是「听起来笃定」。

**一 · 页面只读一次，并且会被裁剪。** 一次点击、`activeTab`、只读你正在看的那个标签页。
导航栏、Cookie 横幅、相似职位栏、申请表单都会在发送前被移除；侧边栏会告诉你滤掉了多少行，
悬停可以看具体内容。**任何过滤规则都不会删掉筛人性条件**——签证担保、执照、安全审查——
因为悄悄删掉一条会直接翻转结论。

**二 · 两份文档都被切成可寻址的块。** 你的简历变成 `CV-001`、`CV-002`…，职位变成
`JD-001`、`JD-002`…，每块大约一个段落。模型只能引用真实存在的块；每一个引用在返回时都会
被还原成原文，还原不了的直接丢弃。这就是阻止它编造证据的机制。但这是**合理性约束，不是
证明**：它保证一条结论指向了真实存在的内容，不保证那段内容真的推得出这条结论。

**三 · 答案的形状是固定的。** 每次请求都带上 JSON schema——包括发给那些无法强制执行它的
模型，以及强制执行被剥掉的回退路径。超出长度限制的回复会被截断而不是拒绝，缺失的段落按空
处理，因为**把你已经付过钱的分析整个丢掉，是更糟的失败**。

**四 · 有些判断放在代码里，不交给模型。**

| 由模型判断 | 由代码判断 |
| --- | --- |
| 岗位是什么、你的简历如何对照 | 雇主条件是否与你声明的状态冲突 |
| 哪些要求会筛掉你 | 结论下方的覆盖计数 |
| 该改什么、该问什么 | 从正文里剥掉块编号 |
| 某一条属于哪个板块 | 什么算页面家具 |

**凡是「出错后既看不见、又足以改变结论」的，都在右边。** 模型被要求不要把 `JD-001` 写进
句子里，它大部分时候听——但「大部分时候」不够，所以由解析器移除。

**五 · 它不会做的事。** 不讲签证路径、配额、办理时长：这里没有任何政策数据，也无法核实
模型「回忆」出来的东西，而**关于资格的一个自信的错误答案，比不回答更危险**。不预测面试
结果。**不给匹配度百分比**——把「满足/部分满足/缺失」压成一个分数，必须给「部分满足」一个
权重，而任何权重都是编的。不给薪资和市场数字，因为这里没有任何东西测量过它们。

**简历优化保持诚实。** 只重组和锐化简历里已有的证据，不会替你添加技能、不会把「参与」升级
成「主导」、不会把团队成果写成个人的，也不会编一个你没有的数字。

## AI 服务与 API Key

Key 由你提供，用量由对方按你的账户计费。

| 服务 | 可选模型 | 去哪里创建 Key |
| --- | --- | --- |
| OpenAI | GPT-5 mini, GPT-5 | [platform.openai.com](https://platform.openai.com/) → API keys |
| Anthropic | Claude Opus 5, Claude Sonnet 5, Claude Opus 4.6, Claude Sonnet 4.6 | [platform.claude.com/settings/keys](https://platform.claude.com/settings/keys) |
| DeepSeek | DeepSeek V4 Flash, DeepSeek V4 Pro | [platform.deepseek.com](https://platform.deepseek.com/) → API keys |

三家都已端到端验证可用。

真正卡住人的不是创建 Key，而是账户余额。**新建的 Key 如果账户没有余额，第一次调用就会
失败**，报错看起来像是插件坏了。请先充值。Key 只在创建时显示一次，丢了就重新建一个。

## 隐私

没有后端、没有账号、没有埋点、没有统计。在你点击分析之前不会发送任何内容。

- PDF **在你的浏览器里**解析，文件从不上传。
- 运行分析时，简历文字和过滤后的职位内容**只发给你选定的那一家服务**，中间没有任何中转。
- Chrome 会在访问服务域名前、以及读取某个网站前分别询问你。
- **从不保存：** PDF、它的提取文字、你的 API Key。
- **会保存：** 界面语言、历次分析耗时。报告只在当前浏览器会话内存在，且**不含任何简历
  原文**——引用的原文在存储前已被剥除。
- **「清除本地会话」**会清掉内存状态和所有已存报告。

侧边栏的**「预览可选 AI 负载」**会原样展示这次运行将要发送的内容，常见个人信息已脱敏。
完整说明见 [PRIVACY.md](PRIVACY.md)。

## 开发

没有构建步骤，没有开发依赖，全部是原生 ES 模块。

```bash
npm install && npm run vendor:pdfjs   # 唯一的运行时依赖 pdfjs-dist
npm run check                         # 静态检查 + 测试 + 审计，唯一的关卡
```

审计覆盖的是跨文件、单元测试看不见的问题：manifest 指向了被删掉的图标、HTML 里改了 id 但
JS 没改、只加了一种语言的文案、没有转义的 `innerHTML`、出现了三家 API 之外的网络地址、
渲染出的 CSS 类在样式表里没有规则、错误码缺少翻译、标记里有没挂翻译标记的可见文本、README
的型号表与注册表不一致、注入到页面里的抓取函数中存在会落入暂时性死区的 `const`。

其中大部分的存在，都是因为对应的 bug **真的发生过一次**。这个项目里有好几类失败是天生
静默的——`t()` 找不到键时会把键名当文案渲染出来；一个把要求过滤掉的过滤器，看起来和「这份
JD 本来就没写这条」一模一样——所以防线必须是机械的，而且每一条都经过反向验证：把 bug 放
回去，确认它确实会失败。
